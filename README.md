A program that writes one original dad joke to `/output/entry.txt` for make.fun's Dad Joke Showdown bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
